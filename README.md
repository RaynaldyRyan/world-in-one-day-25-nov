The World in One Day — Wednesday 25 November 2026. One programmatic flat-vector poster (1024x1024 PNG) summing up the day's news: a three-scene triptych — the Strait of Hormuz closed after three tankers were hit by mines (and the Riyadh attack, 11 hurt), Shenzhou-24 carrying Pakistan's first astronaut to Tiangong, and 15-year-old Vaibhav Suryavanshi's world-record 204* off 53 balls — above a two-column list of the day's 10 other stories, with a DATE CHECK footer for stories from other dates (Microsoft 'Code Red' 24 Nov, GTA 6 release 19 Nov, Nepal PM's India visit 22–23 Nov). Drawn from scratch in TypeScript with a hand-written PNG encoder and bitmap font; no network, no external assets, deterministic output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
